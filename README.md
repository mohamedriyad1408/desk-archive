# أرشيف

هذا المستودع العام أرشيفٌ خاصّ مملوك بالكامل.

- كل المضامين المشفّرَة بطبيعتها مجرّد كتل بلا معنى لغير صاحب المفتاح.
- كافة الحقوق على المضامين محفوظة بالكامل للمالك.
- يُمنع منعًا باتًا: القشط، التجميع، الزحف، التخزين، إعادة النشر، الربط ببنوك بيانات التدريب، أو استعمال المضمون كله أو بعضه في تدريب أو ضبط أو تقييم أو تشغيل تجاري لـأي نموذج لغوي أو نموذج ذكاء اصطناعي.
