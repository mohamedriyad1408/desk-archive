# بطاقة إيقاظ — رقم ٠٠٠ — إلى: (ن/م٢/م١) — التاريخ

- **من:** المستشار الأول
- **المناسبة:** (دفعة بناء / تقاطع بحث / مراجعة م٣ / عاد قرار المالك / خروج)
- **المطلوب:** سطر واحد حرفي قابل للتنفيذ فور الفتح (ولا شيء سواه في هذه الجولة).
- **الأساس/المرجع:** أحدث حجم رقم …؛ الملفات بأسمائها داخل القناة.
- **المدة المقدرة:** … (إلزامية).
- **نقطة المنتصف:** الوقت/الشرط = …؛ فيها مخرَج مختوم واحد بلا إيقاظ أحد.
- **موعد التسليم:** …
- **بعد الإنجاز:** اختم، وأعد تسليح `انتظر.sh <دورك>`؛ البطاقة التالية رقم … (أو: تنتظر كتابتي).
- **أمر الخروج وحده** يُنهي الحلقة: انزع السلاح أولًا ثم `فحص-الخروج.sh <دورك>` (المادة ١٣).
## التسليح بالقلب والعين (توجيه ٠٠٧ — إلزامي مع كل بطاقة تنفيذ/بحث)
1. فور الاستلام: `bash scripts/نبض.sh سلّح <دورك> <رقم البطاقة> <المدة دقيقة>` (نبضة استلام تُدفع، ثم قلب كل ٣ دقائق، وتجلس العين).
2. كود العين **١٠**: `bash scripts/نبض.sh تابع <دورك>` فورًا. كود **١٢**: أنت المرصود غائبًا فعاود؛ **١٣**: اقرأ العائق/النداء؛ **٠**: افتح واقرأ كل الجديد.
3. عائق تفصيلي: `bash scripts/نبض.sh عائق <دورك>` ثم انقشه في الحالة واختم؛ زواله: `نبض.sh جاري <دورك>`.
4. الإنجاز: `bash scripts/نبض.sh سلمت <دورك>` ثم أوقف العين. الخروج بالمادة ١٣ ينزع القلب والعين معًا.
