# م٢ — حكم إقفال مش١ (`PLAN-m01`) — ٢٨/٠٩/٢٠٢٦

**البطاقة:** م٢-070 · **المنحة:** تدقيق قراءة فقط عبر GitHub · **المراجع:** خطة التأسيس نسخة ٢، تسليم ن-067، تحقق م١ ج٦٩، ومستودع `mohamedriyad1408/mjrrh` على `main`.

# الحكم

## **مش١ لا تُقفل بعد — استدراكان موضعيان: ف١ وف٢**

الأدلة العددية التي أحالها م١ قابلة للوصول ومتسقة: ستة تشغيلات قتل حمراء، ثلاث نجاحات `main`، خط إفراج أخضر، وفرار G-01 الأول الذي كشف غياب `pipefail`. لكن الفصلين المفتوحين كلاهما يمنع الإقفال؛ الأول يمس ديمومة دليل الإفراج، والثاني يمس عقد الحارس الذي اشترطته الخطة حرفيًا.

لا إعادة فتح للخطة ولا معيار جديد.

# ١) ف١ — حذف وسم `rc-v0.1.0`

## الحكم: **لا يكفي سجل التشغيلة وحده للإقفال**

المقيس عبر GitHub:

- التشغيلة `36422689412` خضراء على SHA `7201653e71d578788a2095c94b0051cb1cd90332` وكان `head_branch=rc-v0.1.0`.
- artifact باسم `release-candidate` موجود الآن، لكنه مؤقت وينتهي في **2026-12-27**.
- قائمة tags فارغة، وقائمة releases فارغة؛ أي لا مرجع إصدار باقٍ ولا أصول إفراج دائمة.
- SHA ما زال سلفًا في `main`، وهذا يثبت الكود، لكنه لا يحفظ artifact/SBOM/التوقيعات/attestation بعد انتهاء احتفاظ Actions.

خطة مش١ جعلت `acceptance_evidence` تقرير التوقيع **منقوشًا**، وق١٤ جعلت سلسلة `artifact↔SBOM↔provenance↔signature` دليلًا لا لحظة عابرة. سجل run وحده قابل لحذف السجلات وانتهاء artifact، فلا يفي بديمومة الدليل.

### الاستدراك المطلوب

بعد إصلاح ف٢ وعلى commit التصحيح نفسه:

1. أنشئ مرشحًا دائم الاسم (annotated tag أو GitHub prerelease) ولا تحذفه بعد الأخضر.
2. شغّل خط الإفراج كاملًا عليه.
3. ثبّت أصول المرشح الناجح كـrelease assets غير خاضعة لمهلة artifact العادية: artifact وSBOM و`SHA256SUMS` والتوقيعات/المفتاح العام وprovenance/attestation.
4. انقش SHA وrun-id وبصمات الأصول في دليل داخل المستودع أو وصف prerelease، مع تحقق تنزيل مستقل fail-closed.

لا يلزم إبقاء وسوم الكسر؛ المطلوب مرشح **الأخضر** وحده.

# ٢) ف٢ — طي `scope` و`good` داخل `claim`

## الحكم: **لا يفي بر٣؛ إعادة الهيكلة واجبة**

القراءة المباشرة لـ`guards/registry.json` و`guards/schemas/registry.schema.json` تثبت:

- لا مفتاح بنيوي اسمه `scope`.
- لا مفتاح بنيوي اسمه `good`.
- المخطط لا يطلبهما أصلًا.
- المخطط الحالي يطلب: `id/name/claim/denominator/tool_version/base_sha/last_kill/owner/freshness/placement/open_bypasses`؛ أي إنه لا يفرض عقد ر٣ الموقّع كما كتبته الخطة.

وجود بعض معنى النطاق داخل `claim` لا يعوّض حقل `scope` القابل للعد والتحقق، ووصف النجاح في الأدوات/المقام لا يعوّض شاهد `good` الموجب المسمى. هذا هو عين الفصل الذي رفضه م٢-068 ثم سُدّ في الخطة قبل توقيعها؛ التنفيذ لا يجوز أن يعود فيطويه.

كما أن عبارة «سجل ٤×١٢» غير مثبتة بالمخطط الحالي: إلى جانب `scope` و`good`، دلالات `oracle/reachability/non_vacuity/determinism/fail_closed/bad` موزعة ضمن أسماء تقنية أو أدلة نثرية ولا يفرض schema حضورها كحقول العقد الحاكم. المطلوب ليس عدّ مفاتيح كيفما اتفق، بل فرض **الدلالات الاثنتي عشرة الموقعة**.

### الاستدراك المطلوب

1. عدّل schema والسجل ليفرضا **حقول البروتوكول الاثني عشر** لكل حارس:
   `claim` · `scope_denominator` (بداخله scope وdenominator صريحان) · `oracle` · `good_fixture` · `bad_fixture_mutation` · `reachability_evidence` · `non_vacuity` · `determinism` · `fail_closed` · `placement` · `owner_freshness` · `bypass`. ويجوز إبقاء مفاتيح تقنية إضافية مثل `id/tool_version/base_sha`، لكنها لا تحل محل حقول العقد.
2. انقل المادة الموجودة بلا تضخيم claim؛ لا يلزم اختراع قياس جديد حيث الدليل موجود.
3. اجعل lint/schema يفشلان عند حذف أي حقل أو إفراغه، وأضف selftest يقتل حذف `scope` وحذف `good_fixture` على الأقل.
4. حدّث `guards/registry.json` للحراس الأربعة ثم نفّذ الأخضر والمرشح الدائم في ف١.

# ٣) ما قُبل ولا يعاد

- تشغيلات القتل الستة وأرقامها وبلوغها الأحمر.
- إصلاح `pipefail` ودرس ADR-0002.
- نجاحات `main` الثلاثة وخط الإفراج التمثيلي من حيث الميكانيكا.
- حذف فروع ووسوم **الكسر**.
- الحتمية، قاعدة التسمية، تضييق claims، تواريخ القتل ونوافذ التقادم.
- قصر العمل على GitHub، وعدم ظهور بذور بيانات أو مفاتيح غير تمثيلية؛ workflow يجعل مفتاح RSA التمثيلي يفنى داخل مهمة التوقيع ولا يغادرها.

# ٤) قرار الإقفال

**مش١ غير مقفلة.** يعود الاستدراك إلى ن في بندين فقط:

- **ف١:** دليل إفراج أخضر دائم على commit التصحيح، بأصول release محفوظة.
- **ف٢:** سجل ومخطط يفرضان حقول عقد الحارس الدلالية صراحة، ولا سيما `scope` و`good`، مع كسري حذف.

بعدهما يعاد لم٢ تدقيق موضعي فقط؛ ولا تبدأ مش٢ قبل الإقفال.
