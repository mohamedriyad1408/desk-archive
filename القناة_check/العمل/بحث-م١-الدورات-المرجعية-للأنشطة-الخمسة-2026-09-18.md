# بحث م١ — الدورات المرجعية للأنشطة الخمسة (بمصادرها) — مُدخل إلزامي لدفعة غ-٢ — ٢٠٢٦-٠٩-١٨

> **الغرض (وداعم قرار م١ في تعديل م٢/أ):** ملفات المعايرة الخمسة تحمل **أسماء المحطات الثلاثين فقط** — **ولا حقل «مرحلة نشاط» فيها** (قِيس: لا مفتاح يحوي stage/مرحلة/cycle/دورة · والمحطات نصوص عارية: ٦+٥+٧+٦+٦ = ٣٠). **فبدل تأجيل «٣٠/٣٠» أو اختراع الحقل، أُنتج هذا البحث:** **دورة تشغيلية مرجعية لكل نشاط بمصادرها المعلنة**، **تُقابل عليها المحطات الثلاثون كما هي** — **فكل محطة تنال: مرحلة نشاط مرجعية + مصدرها + إسنادها القسمي المقيس** — **بلا مساس بملفات المعايرة (يُثبت بنفي `git diff` فارغ عليها).**
> **قيود محترمة:** صفر رقم سعر/تكلفة (١٠/٢) · صفر ترتيب أهمية (G6 — والتسلسل التشغيلي قبل/بعد لا ترتيب تفضيلي) · والمصادر كلها علنية ومسماة.

## ١) المستشفى — دورة رعاية المريض المرجعية
**الدورة:** `دخول/تسجيل → فرز → تشخيص → علاج/إجراء → رعاية مستمرة (متابعة) → خروج وتسوية`.
**المصادر:**
- **medlaunch.health** (Patient Flow Process): «from arrival and registration **through triage, consultation, treatment**, and **follow‑up**… **Discharge** and transition to follow-up is the final stage». https://medlaunch.health/blogs/patient-care/strategies-to-improve-patient-flow-process/
- **commure.com** (Patient Journey): ست مراحل تنتهي بـ **follow-up** و**ongoing care**. https://www.commure.com/blog/the-patient-journey-in-healthcare-stages-mapping-and-closing-the-gaps
**المقابلة:** المحطات الست **تطابق المراحل المرجعية حرفيًا** («دخول/تسجيل» = registration · «فرز» = triage · «تشخيص» = diagnostics · «علاج/إجراء» = treatment · «رعاية مستمرة» = ongoing care/follow-up · «خروج وتسوية» = discharge).

## ٢) المغسلة — دورة المعالجة المرجعية
**الدورة:** `الاستلام → فرز/تصنيف → تنفيذ (غسيل/كي) → ضبط جودة → التسليم`.
**المصادر:**
- **columbiapikelaundry.com**: «collection, **sorting**, pre-treatment, **washing**, drying, **pressing or finishing**, **quality inspection**, packaging» + «from initial pickup to final **delivery**». https://www.columbiapikelaundry.com/post/commercial-laundry-workflow-arlington-en
- **unitedlaundrygroup.co.uk**: «received and sorted… **Quality Control Happens Before Delivery**». https://unitedlaundrygroup.co.uk/behind-the-scenes-how-a-commercial-laundry-operates/
**المقابلة:** الخمس تطابق: الاستلام = collection/receiving · فرز/تصنيف = sorting · تنفيذ (غسيل/كي) = washing + pressing/finishing · ضبط جودة = quality inspection · التسليم = delivery.

## ٣) شركة البرمجيات — دورة التسليم المرجعية
**الدورة:** `عقد → تخطيط → تنفيذ → مراجعة → اعتماد تسليم → فوترة → دعم`.
**المصادر:**
- **IBM — SDLC**: سبع مراحل: Planning · Analysis · Design · Coding · **Testing** · **Deployment** · **Maintenance**. https://www.ibm.com/think/topics/sdlc
- **TMS — Software Development Process**: «Requirements Analysis → System Design → Implementation (… **code review**) → **Testing & QA** … → **Deployment** → **Maintenance & Support**». https://tms-outsource.com/blog/posts/what-is-the-software-development-process/
- **Juro — CLM**: دورة العقد: creation · **review and negotiation** · **approval** · signing · tracking. https://juro.com/learn/clm-contract-lifecycle-management-software
**المقابلة:** عقد = contract creation/approval (Juro) · تخطيط = Planning/Analysis/Design (IBM) · تنفيذ = Coding/Implementation (IBM/TMS) · مراجعة = code review + Testing (TMS/IBM) · اعتماد تسليم = Deployment + acceptance (IBM/TMS) · فوترة = invoicing (دورة الطلب التجارية — §٤) · دعم = Maintenance & Support (IBM/TMS).

## ٤) تجارة الجملة — دورة الطلب المرجعية
**الدورة:** `طلب/عرض → تعاقد → تجهيز (التقاط) → شحن → التسليم → تحصيل/مطابقة`.
**المصادر:**
- **Cleverence — Sales Ordering Process**: quote → **sales order** → fulfillment → **invoice** → **collections/cash application**. https://www.cleverence.com/articles/for-business/sales-ordering-process-4827/
- **QBC — Wholesale Warehouse Order Management**: «order intake, availability review, allocation, **picking**, packing, **shipping**, invoicing handoff, exception handling». https://www.qbc.com/wholesale-warehouse-order-management
- **Planergy — PO Reconciliation**: **المطابقة الثلاثية** (أمر/استلام/فاتورة) = تحصيل/مطابقة. https://planergy.com/blog/purchase-order-reconciliation/
**المقابلة:** طلب/عرض = quote/order capture · تعاقد = sales order/terms · تجهيز (التقاط) = picking/packing · شحن = shipping · التسليم = delivery (QBC) · تحصيل/مطابقة = invoicing + three-way matching (Cleverence/Planergy).

## ٥) مصنع الأخشاب — دورة الإنتاج المرجعية
**الدورة:** `أمر إنتاج → صرف خامات → قص → تجميع/تشطيب → رقابة جودة → تسليم`.
**المصادر:**
- **daysum.net — Furniture Factory Management**: «**Raw Material Processing**: cutting timber… · **Component Manufacturing** · **Assembly and Upholstery** · **Finishing and Quality Assurance**». https://daysum.net/en/furniture-factory-management/
- **modifurniture.com — Furniture Manufacturing Process**: «design, material selection, **cutting**, shaping, **assembly**, finishing, **quality inspection**, **packaging and delivery**». https://www.modifurniture.com/blog/furniture-manufacturing-process
**المقابلة:** أمر إنتاج = production planning/BOM (daysum) · صرف خامات = raw material processing (daysum) · قص = cutting and shaping (modifurniture) · تجميع/تشطيب = assembly + finishing (both) · رقابة جودة = quality inspection (modifurniture/daysum) · التسليم = packaging and delivery (modifurniture).
