## ٤) ضوابط التطبيق (من زاويتي)
- **لا يفقد التعميم قياسًا** (ضابط م١ الذهبي): كل حادثة تُنقل إلى سجل التعليل بثلاثة حقول، ويُمنع النقل بلا رقم؛ وفحص آلي يقابل «عدد الحوادث المنقولة = عدد صفوف سجل التعليل الجديدة» قبل الختم.
- **أسماء الأدوات تبقى** (`فتح.sh` · `ختم.sh` · `نبض.sh` …) داخل البنود التنفيذية: أدوات الفريق ليست حوادث مشاريع؛ وتُحدَّث نصًا لو غيّر حاجب ١ أسماءها — لا تُمسح.
- **اختبار العموم سؤالان** يُدرجان في إطار الجولة: (١) هل يفهم الحكم بلا الحادثة؟ (٢) هل يصلح لدور/مشروع/وكيل آخر بلا تعديل؟ — وحد الاستثناء المعلن بيد م٢ فقط.
- **الحد الصادق:** مسحي تشغيلي (مواضع ونصوص)؛ النية والسيادة عند م١، والحكم المعياري عند م٢ — أجمع بلا تمثيل.

## ٥) ملحق — الكاشف الآلي (كود جاهز لبوابة النفاذ، لا يُضاف إلى `scripts/` منفردًا)
```python
import re, sys
p = sys.argv[1]; lines = open(p, encoding='utf-8').read().splitlines()
logstart = next((i for i,l in enumerate(lines,1) if 'سجل التعديل' in l and i>600), len(lines)+1)
body = lines[:logstart-1]
pats = {
 'قيد_مرجع':       r'ق-[٠-٩]+|توجيه(ات)?\s*[٠-٩]+',
 'شعار_آلة':       r'القلب|العين|نبض|تنبض|قلب',
 'حادثة_قياس':     r'MB|\d+\s*ساعات|٢٠٢٦|2026',
 'منصة_باسم':      r'GitHub|أرينا|Arena|Supabase|Vercel|Actions|psql|openssl',
 'زمني_حيني':      r'اليوم|هذه الجولة|حاليًا|وقت الكتابة',
 'معرّف_واقعة':     r'v-[٠-٩\d]+|\b[0-9a-f]{7,40}\b',
}
bad = 0
for name, pat in pats.items():
    hits = [i for i,l in enumerate(body,1) if re.search(pat,l)]
    bad += len(hits)
    print(f'{name}: {len(hits)}', hits[:20])
print('exit:', 1 if bad else 0)   # فشل مغلق عند أي نمط محظور
```
