# هيكل الخطة التنفيذية الأولى — **مسودة هيكل م١ (غير تنفيذي — بلا عقد البند بعد)** — ٢٨/٠٩
> **الحالة:** هيكل عمل سابق لتوقيع م٢ على التقييم (بحكمه الصريح: يجوز تجهيز الهيكل لا الاعتماد على «صادق» خارج claims المقيسة). **يُستكمل في الجلسة القادمة** بعقد البند الكامل (ق٢) والنتائج المتوقعة الثمانية (بروتوكول الشرود §٣) والحواسم لكل مهمة — ثم يُعرض للإجماع الثلاثي (شرط المالك ٨). **لا بناء قبله.**
> **السندات الحاكمة:** تفويض المالك الإنشائي ٩ بنود · المنهج المركّب (v-409) · **تقاطع البحث نسخة ٢ الموقَّع ثلاثيًا** · تقييم الوضع القائم نسخة ٢ + §٨ · حكم م٢ (م٢-064/065).

## ٢) تفكيك الخطة الأولى إلى مهام مرقمة (ترتيب طوبولوجي — يُحسم في مسودة العقود)
> الاسم العملي للبناء: **منصة MJRRH** (الاسم المعتمد ٢٥/٠٩). مستودع بناء جديد من الصفر. كل مهمة بعقد ق٢ العشرة + نتيجة متوقعة بثمانية حقول + حواسم.

- **مش١ — العمود الأساسي للمستودع (يُبنى بلا توكن):** بنية المجلدات والطبقات بمبادئ أ١–أ١٢ · قوالب الفروع والمراجعة · فحص أسرار وتبعيات وSBOM (سلسلة التوريد §٦ بروتوكول الشرود) · CI أولي · **سجل الحراس** (بحقول سجل-الحراس المعتمد: مقام/أداة/SHA/آخر طفرة/owner/freshness/placement/bypass).
- **مش٢ — استيراد المحرك كمكتبة:** نقل بتوثيق provenance + SHA خط الأساس · تشغيل ٦٨٦+١ في CI الجديد · طبقة خدمة وعقد API خارجي (WBS ٤٠–٦٦س المشتق) · لا منطق قيد خارج المحرك.
- **مش٣ — العقود والدلالات (طبقة ١ بمبدأ أ١):** المعرّفات والمخططات والحالات والأخطاء وسياسات الصلاحية (الإصدارية → ق٤) · مخطط تعريف **النواة/الرحلة/المحطة/الدور بالبيانات** (أ٣ وحب اختبارَي الإضافة: عينة صعبة + عكسية بقطاع آخر · صفر فرق محرك).
- **مش٤ — الطبقة الوصفية المشتركة (تصميم وهجرة كودًا؛ التطبيق الحي موقوف على توكن Supabase):** سجل العملاء بـallowlist أعمدة + تصنيف + احتفاظ · لا بيانات عميل تشغيلية · اختبار يمنع الحمولة.
- **مش٥ — قالب تزويد العميل الآلي:** الأمر الواحد (مشروع/قاعدة + أدوار + هجرة + بذرة + فحص عزل + جرد) · idempotent · fail-closed · إعادة تشغيل — اختباره المحلي في الحاوية؛ الحي موقوف على التوكن.
- **مش٦ — جسر الأحداث TS↔بايثون:** عقد الجسر بالشروط التسعة (د١) · باجر/عامل للإغلاقات الطويلة خارج حد serverless (مهلة ٦٠ث Pro) · تسوية أولية.
- **مش٧ — الأمن الأساسي P0 (مكونات جدول م٢):** هوية مركزية + MFA مقاوم للتصيد للحساس · deny-by-default للكائن/الخاصية/الوظيفة + مصفوفة صلاحيات سالبة · مدير أسرار + تدوير · حدود كمية (rate/quota/حجم/عمق/وقت) · SSRF allowlist · سجل أمني غير قابل للتحرير بمزامنة وقت · نسخ احتياطي مشفر معزول + تمرين استعادة.
- **مش٨ — مصفوفة الامتثال الخليجي:** ECC 2:2024/CCC 2:2024 · CITRA ٢٦/٢٠٢٤ · PDPPL+PDMS مع DPIA · «ينطبق/لا ينطبق/رأي مخول» + `control→owner→implementation→evidence→cadence→applicability` · مصر: بند مخاطر مفتوح للجريدة الرسمية.
- **مش٩ — أساس الرصد وكشف الأعطال:** OpenTelemetry باصطلاحات دلالية · SLI/SLO-جدول لكل رحلة حرجة الثمانية المتوقعة · قواعد burn-rate الثلاث · عشّار P0–P3 + runbooks — **وتكرار رقمي مؤجَّل لخط الأساس** (ح٨).
- **مش١٠ — مهمة قياس المجمّع (د٥):** ميزانية اتصال علمية لحسم د٥.
- **بوابات توكن مدمجة:** طلب Supabase قبل أول تطبيق حي (مش٤·مش٥·بوابات postgres الـ٣٩/RLS) · طلب Vercel قبل أول نشر (مش٦ تشغيليًا).

## ٣) ما يُستكمل في الجلسة القادمة (بعد توقيع م٢ على التقييم)
- **عقد ق٢ العشرة لكل مهمة** + النتائج المتوقعة الثمانية الحقول + حد التوقف + rollback/compensation.
- **ترتيب طوبولوجي دقيق** يمنع البدء قبل سابقته + سقف خطر كل مهمة + منحة التفويض.
- **خريطة ق** — ربط الخطة بمعايير قبول م٢ ق١–ق١٨ بندًا بندًا.
- **الملاحظة الاقتصادية للمالك في حزمته:** $10/عميل/شهر (Supabase Pro) · Vercel Pro للدرب الطويل — لا نشر قبل علمه وميزانية معتمدة.

**م١ — ٢٨/٠٩/٢٠٢٦ — هيكل غير تقدّمي للبناء؛ لا توقيعات عليه بعد ولا بناء به.**
