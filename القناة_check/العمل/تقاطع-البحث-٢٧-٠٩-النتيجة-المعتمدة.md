## ٣) التعاريف المقفلة (قاموس واحد ملزم — لا يُعاد تأويله)

| المصطلح | التعريف المعتمد |
|---|---|
| **الحارس الصادق** | عقد إثبات باثني عشر حقلًا (س٣) — لا سكربت أخضر |
| **الحارس الكاذب** | أي حارس يعلن نجاحًا مع كسر ممثل باقٍ، أو على مقام مجهول، أو بعد skip/خطأ أداة، أو لأن المؤثر لم يصل، أو لأنه يقارن الشيء بنفسه |
| **الشرود** | حافة اعتماد ممنوعة · أثر جانبي غير متعاقد · ملف/جدول/صلاحية خارج قائمة الخطة · نتيجة فعلية خارج الأثر المتوقع · قرار جديد بلا `source_ref` · bypass غير منتهٍ · أو «إصلاح» يغيّر المعيار ليمر |
| **النتيجة المتوقعة** | أثر مسمّى بمدخلات وإصدار وبيئة + زاوية تحقق + نفي + حد توقف + rollback-or-compensation |
| **يقين ١٠٠٪** | اكتمال العقد والدليل داخل مقدماته (س٥) — لا وعد انعدام العطل |
| **خط الأساس** | SHA/إصدار/تاريخ مثبَّت للواقع المقاس، لا يتحرك أثناء القياس |
| **الاستيراد** | أخذ أصل بشروط ق١٥ السبعة — لا ذكر اسمه في خطة |
| **العزل** | قاعدة/مشروع مستقل لكل عميل + هوية مستأجر في كل سجل + RLS داخلية + مشترك وصفي فقط |
| **الحقيقة الدائمة / الحمولة القابلة للمحو** | فصل ح٣ — ولكل منهما احتفاظ ومحو وإتلاف معلن |
| **SLI/SLO/ميزانية الخطأ** | مؤشر ← هدف ← المسموح من عدم الموثوقية (١−SLO) في نافذة معلنة |
| **TTD/TTA/TTI/TTC/TTR** | كشف ← إقرار ← تصنيف ← احتواء ← استعادة SLI (لا إغلاق التذكرة) |
| **Customer-first ratio / Alert precision** | حوادث اكتشفها العميل أولًا ÷ ذات الأثر · والتنبيهات القابلة للفعل ÷ كلها |
| **kill-rate / non-vacuity / fail-closed** | نسبة الطفرات المعلنة التي يقتلها الحارس (١٠٠٪ للحرج) · دليل وجود المدخلات · الرسوب عند خطأ الأداة أو غياب المصدر |

## ٤) فرز الصناديق الأربعة (المنهج §١/٧)

**① داخل الخطة** (يُمتص في الخطط التنفيذية): المبادئ المعمارية **أ١–أ١٢** · عقد الحارس ١٢ حقلًا · اختبارات كشف الكذب السبعة · طبقات الاختبار الأربع (تغيير/دمج/مرشح إصدار/دوري) · **معايير قبول الخطط ق١–ق١٨** · مكونات الأمن **P0 فأولًا ثم P1 ثم P2** · مصفوفة الامتثال `control → owner → implementation → evidence → cadence → applicability` · نتائج الصيانة وكشف العطل بمقاييسها (والعتبات بعد خط الأساس) · شروط الاستيراد ق١٥ · تصحيحات بروتوكول منع الشرود س١–س١٠.
**② حزمة مالك** (تُجمع وتُرفع دفعة واحدة، لا إفرادًا): **حذف المستودع الفارغ `MJRH-INDUSTRIAL-REVOLUTION-`** (فعل لا رجعة فيه ⇒ بوابته) · **أرشفة `MJRH` القديم** (توصية ن) · **طلب توكنَي Supabase وVercel** عند أول مهمة تحتاجهما (بند ٧ من تفويضه) · **رأي قانوني مخوَّل** في انطباق ECC/CCC وCITRA ٢٦/٢٠٢٤ وPDPPL على الكيان والعقد (م٢ §٧) · **اعتماد ميزانية** للأدوات الأمنية ومناطق الاستضافة (P1 عالية الكلفة).
**③ معوّق تمثيل شخصي:** لا شيء مفتوحًا الآن.
**④ فجوة معرفة** (تُسد في تقييم الوضع القائم): نسبة تغطية المحرك · السلوك تحت الحمل · أرقام TTD/TTA/TTR ودقة التنبيهات · كلفة الموردين والعملات ومناطق الاستضافة · حالة النشر الحي · فرق `drytech` تفصيلًا · عدد دفعات `MJRH-INDUSTRIAL-REVOLUTION` كاملًا — **ويُضاف إليها صراحةً باعتراض م٢:**
> ١. **صدق حراس `mjrh-engine` وفق العقد الاثني عشر** (لا وفق عدّ الفشل وحده) — بإعادة good/bad/reachability من نسخة نظيفة.
> ٢. **تثبيت تاريخ/نفاذ اللائحة المصرية** من مصدر رسمي (الجريدة الرسمية/الجهة المختصة).
> ٣. **صلاحية وكلفة ورخصة ومسار خروج** `enterprise-ai-os` و`agent-knowledge` وبوابات/أنماط `MJRH` (ق١٥).
> ٤. **قياس متطلبات ح٢ واختيارها** بعد مقارنة البدائل والحمل.
> ٥. **سلطة إنشاء/رفع `Legal Hold`** بحسب الاختصاص والرأي المخوَّل.

## ٥) ما يُعتمد ملزمًا بعد التوقيع

1. **المبادئ المعمارية أ١–أ١٢** (بمقاييس رسوبها) — وهي **مبادئ الهندسة والمعمارية** التي اشترط المالك اتفاقنا عليها (بند ٨).
2. **عقد الحارس (١٢ حقلًا) + اختبارات كشف الكذب السبعة + طبقات الاختبار الأربع** — وهي جواب «الحراس الكاذبة».
3. **معايير قبول أي خطة تنفيذية ق١–ق١٨** — موقّعة مسبقًا من م٢ قبل رؤية أي خطة.
4. **جدول مكونات وقف القرصنة بالأولوية P0/P1/P2** + **قاعدة الشراء** (لا أداة قبل تحديد الادعاء والمقام والتكامل والمالك وكلفة الضجيج ومسار الخروج).
5. **مصفوفة الامتثال بالنسخ الحديثة** (ح٩) + قاعدة: ما يتعارض بين الأسواق يُفصل **بسياسة اختصاص**، لا بأقل قاسم حماية.
6. **النتائج المعمارية المقبولة بمقاييسها** (§٣-أ و§٣-ب) — **والعتبات الرقمية مؤجلة إلى خط الأساس** (ح٨).
7. **شروط الاستيراد** (ح١٠ + س١٢) — و**كل استيراد مرشَّح مشروط بق١٥** لا قرار ناجز: المحرك · Knowledge/Tool OS · الأصول المعرفية · بوابات MJRH وأنماطه · وأي انتقاء من كتلة `MJRH`. **ولا استيراد كتلي افتراضي** (ح١٥ مصححًا).
8. **بروتوكول منع الشرود بعد تصحيحاته العشرة** — ويُلزم م١ بإصدار **نسخة ٢** منه مطابقة لهذا التقاطع.
