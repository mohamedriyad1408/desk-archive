# بذرة المسرد الحاكم — النسخة ٣٫٠ (R3-R7) — ٢٠٢٦-٠٩-٢٩

> مصطلح واحد لكل مفهوم، لا مرادفات بين المواد. تُمدّ البذرة ببوابة تحكم لا تحريرًا سائبًا، وتقابلها الإنجليزية عند clause_mapping.

| المصطلح | تعريفه الحاكم |
|---|---|
| الأثر الموحد | المقروء المختوم + المضمر المستفى المُقَرّ — يجتمعان بندًا واحدًا يُبلور ويوجَّه |
| سلطة القرار | صاحب النية والقرارات الكبرى وأفعال التمثيل الشخصي — المالك في هذا المشروع |
| قوة الحق | الاعتماد بقوة البحث المكتمل العمق — لا بالسيادة ولا بالخبرة |
| حلقة الكمال | رجوع الناقص لسلطة القرار بتبيان النقص وتعليم الأسس عند اللزوم حتى الاكتمال |
| متجه الدليل | [S,X,N,R,A] أبعاد متعامدة لا سلم تراكمي — البعد الحرج الصفري يسقط الادعاء |
| لا صفر أخضر | A إما ١ عند انطباق الإذن أو N/A بسبب مكتوب — لا A=0 يقرأ نجاحًا |
| عقد البند | معرف · غرض · نطاق · افتراضات · معايير · أدلة · مسؤول · اعتماديات · اكتمال |
| مصير كل مطلب | requirement_disposition — واحدة من خمس لا تختلط بالمسارات |
| مسار كل اكتشاف | discovery_routing_bin — واحدة من أربع بنية مستقلة عن المصائر |
| البروفايلات الأربعة | risk · intake · evidence · advocacy — ثلاث درجات ولا درجة صفرية |
| سجل الاستيفاء | أبعاد نوع المخرج قبل العمل + تصنيف المجهول + VOI + بوابة blocking_open=0 |
| بيان التفعيل | activation manifest — لا نفاذ لحكم قبل نشر أداته وبروفايله واختباراته |
| لا-فقدان | سلسلة تراكمية حية (manifest+tombstones+reconciliation) لا آخر حجم وحده |
| ناشر الحالة | status publisher — تمثيل الحضور الدوّار (اسم محايد) |
| راصد الأحداث | event watcher — مراقب الأحجام والنداءات (اسم محايد) |
| البنية الطبقية | Core كوني + Team Topology + Execution Environment + Project/Domain + Rationale Ledger |
| سجل التعليل | الطبقة الخامسة غير المعيارية — الحوادث ودروسها؛ التعميم لا يحذف الدرس |
| سجل الناسخ | جرد المصادر الحاكمة ببصماتها ورأسها الفعلي وحالاتها |
| الخيار الافتراضي |  reversible-default معلن بافتراض وrollback وانتهاء صلاحية — لا يُختلق لحاجب |
| السابقة الحية | استشهاد واحد (SHA + حجم) من الأرشيف يُستأنس به في مثل العمل |
| ادفع قبل أن تفصل | آخر فعل قبل أي توقف: ختم ودفع وتحديث حالة |
| cold-start | وكيل بلا ذاكرة يصل من الأوراق وحدها إلى القرار وحدوده |
| بروفايل-واو | آلية مشروع عامة بثلاثة أغراض (حدود · تعليم · توجيه) — لا يُذكر فيها اسم مشروع مخصوص (بتّ ص-واو) |
| بطاقة الإقلاع | صفحة الدخول المختومة لكل دور: أول ١٠ أفعال وما يُقرأ حالًا — الدستور مرجع لا تحميل (بتّ ص-ج٣) |
| اقتصاد القيمة | المادة ١٩ بعد البتّ: البناء على أفضل وأغلى والكلفة تُقاس عائدًا ضمن سقف معلن (ص-أ٤) |
| الاستنساخ الجزئي (partial clone) | المسار المرجعي لقراءة القناة وختمها: blobless + sparse بذروة ≈٣٠MB مقيسة (ق-٠١٠) — والكامل استثناء معلن |
| المعوق الشخصي (representation_blocker) | التمثيل الشخصي عائق لا يُهندَس (المادة ١٧) — التعريب والمعرّف معرّف واحد (المسرد الحاكم) |
| representation_blocker ≡ personal_representation_blocker | معرّف واحد بعضوين: Core م٩/٣ والأداة يكتبان الأول وواو v1.1 §١ يكتب الثاني — سطر مكافئة بقرار م١ ٣ (بلا v1.2 وبلا مساس بالنص الموقّع) |

| الملحق المعياري ٢ | العدسات والمنهج الخماسي (ANNEX-LENS/v1) — عدسة تطبيق داخل مراحل م٧ لا بديل ولا موازٍ؛ عند التعارض Core يحكم (ص-ع١) |
| ANNEX-LENS/v1 | معرّف الملحق المعياري ٢ في سجل الناسخ وجدول المعرفات (ص-ع١١) — ثمانية أقسام |
| المنهج الخماسي | خ-١ قياس ← خ-٢ جذر ← خ-٣ تخطيط ← خ-٤ تنفيذ ← خ-٥ إثبات حي — لا تُقفل مرحلة قبل مخرجها، والعدسات الثلاث (ع١/ع٢/ع٣) كل عدسة بخمسة مخرجات |
| الفئتان | أ = يُصلح منفصلًا ويُعلن فورًا (حد أمان م١٠/٧ أو external-critical) · ب = يُذكر ولا يُصلح إلا بقرار واعٍ موثّق (deferred_with_reason م٩/٣) |
| إهمال عدسة | غياب مخرج بلا N/A بسبب معلن · أو مخرج بلا دليل مرفق · أو بدء مرحلة قبل إقفال سابقتها (الملحق المعياري ٢/٥) |
| زاويتان مستقلتان | قتلتان مميزتان تُسجَّلان قبل الكود بأربعة حقول (الزاوية · الافتراض · العطل المحقون · ناتج الفشل) — واختبار الرفض: تشابه الافتراضين ⇒ زاوية واحدة (ص-ع٥) |
| جدول المعرفات | بند → معرّف → إصدارة → بصمة → موضع القيد — إجلال تعريف الحزمة الحاكمة (ص-ع١١) ويُنشر بالرزمة |
| سقف البوابات | اعتماد ≤٦٠د · تجميد ≤٦٠د · إصدارة ≤١٢٠د · نفاذ ≤٣٠د — مبدئي يُقاس بخمس مهام فتُثبَّت (الملحق المعياري ٢/٨) |
| التقرير الختامي الواحد | جدول ١٥ صفًا مقيّدًا + سجل مراحل بأرقام خ + فئة أ/ب + المؤجلات + «لم يُقَس» + «ما تبقى مفتوحًا» (ص-ع٦) |
| نطاق القياس وما خرج عنه | السطر الخامس لكل دليل مرفق (ص-ع٧) — مسبار يقيس الفاشل فقط كان سبب S-3 الحقيقي |
