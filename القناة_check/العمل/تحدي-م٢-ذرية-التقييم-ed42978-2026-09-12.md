## قياس واقع لا استنتاج من خضرة الحزمة
على استنساخ نظيف ورأس `ed42978`:
- الحزمة القائمة **313 اختبارًا OK** (1.330 ثانية)، وCI-GATE PASS.
- لكن `MonthlyRevaluation.revalue(..., settle=True)` يمرر settle=True إلى `post_financial`، فيلتزم القيد **قبل** إدراج `valuation_runs` و`valuation_lines`؛ ثم يرجع دون التزام السجلين.
- من اتصال ثانٍ بقاعدة ملفية، فور رجوع الاستدعاء الناجح: `journal_entries=1`، `valuation_runs=0`، `valuation_lines=0`.
- rollback للاتصال الأصلي يترك الأرقام نفسها: قيد مالي دائم بلا سجل تقييم ولا أسطر تعرّضات، فتُفقد بيانات العكس.
- زاوية ثانية: حقن فشل BEFORE INSERT في valuation_runs ثم استدعاء جديد، وبعد الاستثناء والرجوع: `journal_entries=2`، `valuation_runs=0`، `valuation_lines=0`. أي أن النداء الفاشل أضاف قيدًا دائمًا أيضًا.

هذه ليست مشكلة `is_sealed=0` السابقة (ف-٠٢ مغلقة)، بل انشطار العملية الأوسع بعد قيد مختوم. لا إعادة فتح لف-٠٢ القديمة.

```python
import tempfile, sqlite3
from pathlib import Path
from code.db import DatabaseManager
from code.accounts import TenantProvisioner
from code.currencies import CurrencyRegistry, ExchangeRates

with tempfile.TemporaryDirectory() as td:
    path = str(Path(td) / 'probe.sqlite')
    db = DatabaseManager(path)
    db.init_db()
    c = db.get_connection()
    TenantProvisioner(c).provision_tenant('probe', 'wholesale')
    ExchangeRates(c, CurrencyRegistry(c)).set_rate(
        'USD', 'EGP', '2026-09-30', '50', source='MANUAL_CBE',
        evidence_url='https://example.invalid/test')
    c.commit()
    v = MonthlyRevaluation(c)
    exp = [{'account': '1-12-125-1251', 'currency': 'USD',
            'foreign_amount': '100', 'book_base': '4000'}]
    tables = ['journal_entries', 'valuation_runs', 'valuation_lines']
    v.revalue('probe', '2026-09-30', 'EGP', exp,
              fx_account='6-61-611-6111', settle=True)
    with sqlite3.connect(path) as p:
        print('success', {t: p.execute('SELECT COUNT(*) FROM '+t).fetchone()[0]
                          for t in tables})
    c.rollback()
    c.execute("CREATE TRIGGER probe_fail BEFORE INSERT ON valuation_runs "
              "BEGIN SELECT RAISE(ABORT,'injected-run-failure'); END")
    c.commit()
    try:
        v.revalue('probe', '2026-09-30', 'EGP', exp,
                  fx_account='6-61-611-6111', settle=True)
    except sqlite3.IntegrityError as exc:
        print(exc)
    c.rollback()
    with sqlite3.connect(path) as p:
        print('failure', {t: p.execute('SELECT COUNT(*) FROM '+t).fetchone()[0]
                          for t in tables})
    db.close()
```
