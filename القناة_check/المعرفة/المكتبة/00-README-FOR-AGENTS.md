# مكتبة معرفة الوكلاء — دليل التحميل عند التجنيد

> **الغرض:** هذه المكتبة هي **كنز المعرفة والتجارب** المستخرج من كل ريبوهات المالك (يونيو–سبتمبر ٢٠٢٦).
> يُحمَّل محتواها **إلزاميًا عند تجنيد أي وكيل** لأي مهمة على أي ريبو، مع وثيقته الدستورية الحاكمة وبطاقة دوره.
> **القاعدة:** لم تُكتب لتروى — كُتبت لتُحمى من تكرار الفشل. كل حكم هنا **مقيس وموثق بمصدره** داخل الريبوهات.
>

## كيف تُستعمَل (تسلسل التجنيد)

```
١. الوثيقة الدستورية الحاكمة (AOP)          ← كيف تعمل
٢. بطاقة دورك (مستشار أول / ثانٍ / منفذ)    ← حدودك
٣. وعي المالك (07-OWNER-PROFILE)            ← لمن تعمل
٤. خريطة الريبوهات (01-REPO-LINEAGE)        ← أين أنت ومن أي عصر
٥. المبادئ المثبتة (05-VALIDATED-PRINCIPLES) ← ما لا يُعاد اكتشافه
٦. سجل «لا تكرر» (06-NEVER-AGAIN)           ← الجراح المغلقة
٧. أنماط النجاح (04-SUCCESS-PLAYBOOKS)      ← كيف أُنجزت المهام
٨. كتالوج المعوقات (02-OBSTACLES)            ← ما الذي سيوقفك أخيرا
٩. أسباب الفشل (03-FAILURE-ROOT-CAUSES)     ← كيف ماتت التجارب
```

تسع وثائق (مع هذه). مصدر كل دليل مذكور باسمه داخل `Evidents-doc` أو الريبو ذي الصلة — ارجع للأصل عند الحاجة.
**لا شيء هنا يُعدَّل بالرأي** — كل تحديث لمكتبة المعرفة بدليل جديد (راجع قسم سياسة التحديث آخر الملف).

هذه المكتبة **غير تشغيلية**: كتب رؤية وتجربة، لا كود ولا مخطط قاعدة. الكود المصدر في ريبو المنتج المعني.

## سيادة الملفات

1. عند التعارض: **الوثيقة الدستورية (AOP) ثم هذه المكتبة ثم وثائق الريبو المحلية ثم الكود.**
2. عند تعارض «الكود المنشور» مع «المستودع» — هذا **حادث انحراف خطير** (عولج مرارا، راجع ف-٠١)؛ قف ووثق، ولا تفترض أيهما الحقيقة قبل القياس.
3. هذه المكتبة تسكن ريبو الأدلة `Evidents-doc` حصرا، وتُنسخ موسومة برقم إصدارة في أي ريبو يحتاجها.
4. **فقدان النص العربي أو انقلاب الحروف اللاتينية داخله = حادث حوكمة**؛ المالك يقرأ بالعربية حصرا، وتُفحص النصوص قبل الدفع.

## سياسة التحديث

- كل مهمة مكتملة (ناجحة أو فاشلة) ترشّح درسا: ملاحظة ثم نمط (حالتان متنوعتان على الأقل) ثم قاعدة (ثلاث حالات متنوعة) ثم قيد دستوري (باعتماد المالك).
- التحديث في ريبو الأدلة فقط، وأرقام الإصدارة في النسخ الموسومة تحدَّث بالتزامن.
- **صدق التصنيف:** كل تجربة تصنَّف بوضوح:
  - علامة نجاح: مثبت حيا بأدلة.
  - علامة صدق بلا تنفيذ: موثق بالكامل ولم يبنَ أو يُنشَر.
  - علامة فشل: كُسر أو هُجر أو كذب على الواقع.
- التصنيف الخاطئ المتعمد (تجميل فشل أو تضخيم نجاح) إخفاق جوهري لا يقل عن الفشل نفسه.
