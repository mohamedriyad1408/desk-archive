# بطاقة إيقاظ — ن — ٠٦٨: **استدراك إقفال مش١ — بندان موضعيان فقط (ف١ ديمومة دليل الإفراج · ف٢ بنيوية عقد الحارس) — بمنحة خطية**
**٢٨/٠٩ · من م١ بحكم م٢ (`م٢-حكم-إقفال-مش١-٢٨-٠٩.md` · نقش ج٣٦) · المخرَج: نقوش تنفيذ + أخضر جديد + مرشح دائم بأصول release — ثم تسليم لم٢ بتدقيق موضعي**

## المنحة الخطية للاستدراك
- **النطاق:** مستودع `mjrrh` حصرًا — تنفيذ البندين أدناه حرفيًا بمعايير قبولهما كما كتبها م٢. **لا شيء آخر:** لا إعادة تصميم، لا توسيع حراس، لا لمس ما قبله م٢ (القتلات الست · pipefail/ADR-0002 · ميكانيكا الإفراج التمثيلية · حذف فروع/وسوم الكسر · الحتمية · قاعدة التسمية · تضييق claims · التزام GitHub والمفاتيح التمثيلية).
- **سقف الخطر:** **متوسط additive — على `mjrrh` فقط**. التوكن في البيئة يُحصر في **GitHub فقط** (قراءة + دفع على هذا المستودع) — لا مكالمة خارجه.
- **الانتهاء:** نهاية البطاقة (٣٠٠ دقيقة) وتُمدد بمنحة جديدة.
- **الشروط الدائمة:** انقش بعد كل مرحلة واختم · لا «صادق» خارج claim مقيس · خطاف الاستدراك ببروتوكول الشرود نسخة ٢.

## ف١ — دليل إفراج أخضر دائم (معايير م٢ الحرفية)
بعد إصلاح ف٢ و**على commit التصحيح نفسه**:
1. أنشئ مرشحًا **دائم الاسم** (annotated tag أو GitHub prerelease) **ولا تحذفه بعد الأخضر**.
2. شغّل خط الإفراج كاملًا عليه.
3. ثبّت أصول المرشح الناجح كـ**release assets** غير خاضعة لمهلة artifact العادية: artifact · SBOM · `SHA256SUMS` · التوقيعات/المفتاح العام · provenance/attestation.
4. انقش SHA وrun-id وبصمات الأصول في دليل داخل المستودع أو وصف prerelease، **مع تحقق تنزيل مستقل fail-closed**.
- وسوم الكسر تبقى محذوفة — المطلوب مرشح **الأخضر** وحده.

## ف٢ — فرض حقول العقد الاثني عشر بنيويًا (معايير م٢ الحرفية)
1. عدّل schema والسجل ليفرضا لكل حارس: `claim` · `scope_denominator` (بداخله scope وdenominator صريحان) · `oracle` · `good_fixture` · `bad_fixture_mutation` · `reachability_evidence` · `non_vacuity` · `determinism` · `fail_closed` · `placement` · `owner_freshness` · `bypass`. ويجوز إبقاء مفاتيح تقنية إضافية (`id/tool_version/base_sha`…) لكنها **لا تحل محل حقول العقد**.
2. انقل المادة الموجودة **بلا تضخيم claim** — لا اختراع قياس جديد حيث الدليل قائم.
3. اجعل lint/schema **يفشلان عند حذف أي حقل أو إفراغه**، وأضف selftest يقتل **حذف `scope` وحذف `good_fixture`** على الأقل (قتلتان بأرقام وصول كعادتك).
4. حدّث `guards/registry.json` للحراس الأربعة، ثم أخضر CI، ثم مرشح ف١ الدائم.

## الإقفال
انقش ثم اختم وسلّم نبضًا — **ولا يظهر في المحادثة عند الإقفال إلا: (م١)**. عند تسليمك يعود الحكم لم٢ بتدقيق موضعي على البندين فقط؛ وبقبوله يُقفل م١ مش١ ويصدر منحة مش٢.
